# BreastCancerCare AI — Source Files

هذا المجلد يوضح مكان ملفات المصادر التي يستخدمها المشروع.

## الملفات المحلية المضمنة

| الملف | الاستخدام |
| --- | --- |
| `client/public/sources/life-after-treatment.pdf` | نسخة محلية من مورد NCI عن الحياة بعد علاج السرطان، ومتاحة أثناء التشغيل عبر `/sources/life-after-treatment.pdf`. |
| `server/medicalKnowledge.ts` | سجل المصادر الموثوقة وملخصاتها ثنائية اللغة الذي يستخدمه الرد الثابت في الواجهة. |
| `client/src/lib/staticRag.ts` | منطق اختيار المصدر والإجابة المحلية عند تشغيل النسخة بدون API أو قاعدة بيانات. |

## المصادر الخارجية المرتبطة

الردود تعرض روابط المصادر الأصلية للتحقق منها، ومنها منظمة الصحة العالمية، والمعهد الوطني للسرطان، والجمعية الأمريكية للسرطان، وNCCN، وASCO، ومؤسسة بهية.

هذه المواد للتثقيف العام وليست تشخيصًا أو خطة علاج فردية. يجب مناقشة أي قرار طبي مع فريق الرعاية.

## التشغيل المحلي

بعد فك الضغط:

```bash
pnpm install
pnpm dev
```

ثم افتحي `http://localhost:3000/chat?lang=ar`. لا يحتاج المسار الثابت إلى قاعدة بيانات كي يعرض المحادثة أو المصادر المضمنة.
